# Cheatsheet

Opened by `cmd-k cmd-m` in Zed (task `cheatsheet`).

## Zed

### Markdown
- `cmd-shift-v` in a preview — show source (edit the file); every `.md` opens as a preview (`markdown_preview.open_markdown_files_in_preview`)
- `cmd-shift-v` in source — open the preview (only needed if the file opened as source)
- `cmd-k v` — open the preview to the side

### Keybindings
- `cmd-k cmd-s` — keymap editor (search any action and its binding)
- `cmd-k cmd-v` — toggle vim mode
- `cmd-k cmd-m` — open this cheatsheet
